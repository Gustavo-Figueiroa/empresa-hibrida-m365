# Projeto: Ambiente Híbrido Microsoft 365

Este projeto simula a implementação de infraestrutura híbrida para uma empresa de médio porte.

## Tecnologias Utilizadas

- Windows Server 2022
- Active Directory
- Azure AD Connect
- Microsoft 365
- PowerShell

## Objetivos

- Gerenciamento centralizado de identidade
- Segurança com MFA
- Governança de acesso
- Automação de provisionamento

## Estrutura do Projeto

/docs -> Documentação técnica
/scripts -> Automação PowerShell
